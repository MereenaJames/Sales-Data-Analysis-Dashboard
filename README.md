# Sales Data Analysis Dashboard

## Tools Used
- Excel
- SQL
- Power BI

## Project Overview
Built a Sales Data Analysis Dashboard to analyze retail sales performance and business trends. Performed data cleaning in Excel, SQL analysis for insights, and created an interactive Power BI dashboard with KPI cards, charts, and slicers.

## Key Insights
- West region generated highest sales
- Technology category achieved maximum profit
- Sales increased during year-end months

## Features
- Interactive dashboard
- SQL analysis queries
- KPI cards and charts
- Business insights visualization
